# 解析品牌图标

`jiexi-mark-source.png` 是本项目 4.0 使用的原始品牌母版。Windows 与 Android 的发布图标均由该母版等比缩放生成；不得从 ChatGPT、OpenAI 或其他第三方商标文件复制图形。

生成工具：OpenAI ImageGen

生成提示词：

> Create a single original app logo mark for a Chinese desktop and Android utility named “解析” that combines public video downloading and cloud-drive link parsing. Visual direction: a continuous near-black monoline ribbon forming a compact four-way knot/link symbol, with a subtle downward-flow/download cue integrated into the lower stroke. Transparent background, no enclosing tile, no text, no letters, no gradients, no colored fill, no shadows, no 3D, no mockup. Geometric, balanced, memorable at 16 px, with generous negative space and rounded stroke terminals. It may evoke the simplicity and interlocking logic of modern AI-product icons, but must not copy the ChatGPT/OpenAI knot, proportions, rotation, topology, or silhouette. Centered square composition, production-ready logo asset.

发布时请保留本目录中的母版，并使用 `desktopApp/src/main/resources/icon.ico`、`icon.png` 以及 `app/src/main/res/drawable/icon.png` 作为平台成品。
