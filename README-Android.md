# 解析 Android 版 4.1.0

## 安装与升级

1. 下载 `JieXi-4.1.0-Android.apk`。
2. 在系统提示时允许当前文件管理器安装未知来源应用。
3. 首次安装后，今后可以直接覆盖安装由同一发行证书签署的新版本。

4.0.0 的普通公开 APK 使用新的 RSA 4096 位发行证书，不会伪装成早期 debug 测试版的签名。若手机中装有旧测试版：

- Android 7–12（API 24–32）不能直接覆盖，需先卸载旧测试版；旧测试版的本机数据会随卸载清除。
- Android 13 及以上（API 33+）如需保留旧测试版数据，请先通过 GitHub Issues 或反馈邮箱索取单独的迁移 APK。迁移 APK 仅用于这一次签名迁移，不作为普通公开 Release 附件。
- 不确定当前安装来源时，先导出可导出的数据并记录设置，再处理签名冲突。

## 使用

- 解析：首页粘贴网盘或视频链接，自动识别类型并显示对应结果。
- 下载：切换「网盘与文件 / 视频与音频」管理任务。
- 我的：收藏、历史、网盘账号、媒体工具、外观、设置、诊断、更新与赞赏。
- 系统分享：在浏览器或其他应用点“分享”，选择“解析”。
- 后台任务：下载使用前台服务；通知栏可查看状态，媒体任务支持暂停、继续和取消。
- 本地工具：图片局部修复、MP3 提取和视频截图都在手机本地完成。

公开媒体默认保存到 `Download/解析`。网盘任务保存到系统下载目录，或保存到设置里授权的文件夹。Android 13 及以上请允许通知，以便后台下载状态不会被系统隐藏。

## 画质与登录

公开视频页默认选择匿名状态下原站实际提供的最高开放画质；原站开放 4K/8K 时才会出现对应格式。**登录入口：我的 → 网盘与账号 → 选择对应平台 → 登录**。浏览自己的网盘、管理/转存文件必须登录；迅雷分享解析及夸克、百度、123 分享下载需要账号授权。UC、139 会先尝试匿名开放通道，失败时仍可能要求登录。软件不绕过 DRM、会员或付费权限。

## 更新与反馈

设置页会读取作者 RSA 签名的更新清单。APK 下载完成后先核对 SHA-256、包名、版本号和发行证书，再由 Android 系统安装器复核签名。反馈地址为 [GitHub Issues](https://github.com/chanha666/JieXi/issues/new) 和 `3316109338@qq.com`。
