# 解析 Windows 版 3.1.0

支持解析夸克、UC、迅雷、百度、139 和 123 云盘分享链接，浏览分享目录并下载文件。本仓库现仅维护 Windows 桌面版。

## 安装版（推荐）

1. 双击 `JieXi-3.1.0-Setup.exe`。
2. 按安装向导选择目录并完成安装。
3. 从桌面快捷方式或开始菜单打开 `解析`。
4. 不再使用时，可在 Windows“设置 → 应用 → 已安装的应用”中卸载。

安装版默认安装到当前用户目录，不要求目标电脑预先安装 Java。

## 绿色版

1. 解压完整压缩包，不要只复制其中的 EXE。
2. 双击 `解析.exe`。
3. 直接在“解析链接”中粘贴公开分享链接和可选提取码，无需提前登录。
4. 选择文件并下载。默认目录是 Windows 的“下载”文件夹，可在“设置”里修改。
5. 只有服务方强制要求授权时，才到“云盘登录”点击唯一的“登录”按钮。

## 软件内登录

1. 打开“云盘登录”，找到对应网盘。
2. 点击“登录”。界面不再显示 Chrome、Edge、Cookie 输入或“网页登录”等重复入口。
3. 在“解析 · 云盘登录”内置窗口中完成登录。
4. 点击窗口右上角“登录完成并导入”。

内置直接登录目前用于夸克、UC、百度和 139；登录资料放在“解析”的隔离目录中，不读取日常浏览器数据，导入结果由 Windows DPAPI 加密保存。123 云盘和迅雷的接口使用 Token，仍保留 Token 配置方式。

应用已包含专用 Java 运行环境，目标电脑不需要另装 Java、Android Studio 或其他开发工具。

## 下载策略

- 自动探测服务器是否支持分段下载。
- 智能选择有效分片数，上限可设为 8、16、32、48 或 64 路；默认使用单任务满速 48 路。
- 每个分片至少约 4 MB，避免小文件被过度切分；大文件自动使用更多连接。
- 服务器忽略 Range 时自动回退为单连接，避免生成损坏文件。
- 下载中断时保留 `.yunx-parts` 临时分片，重新下载同名文件可续传。
- 下载任务可从列表删除；删除正在下载的任务会先取消其网络请求，不会误删已经完成的文件。
- 仅允许 HTTPS 下载地址；文件名会移除 Windows 非法字符。
- 临时直链失效或网络抖动后，任务会重新解析新直链并从已有分片继续。
- 可选择系统代理、直连、HTTP 或 SOCKS5；下载时可阻止系统休眠。

## 账号与隐私

- 139 公共分享支持免登录下载；UC 会优先匿名尝试；夸克、百度、123 公共分享支持免登录浏览目录。
- 夸克、百度、123 的文件下载，以及迅雷的解析/下载，受服务方官方接口限制，需要对应账号授权。
- 凭据仅保存在当前 Windows 用户的本机配置中。
- 凭据使用 Windows DPAPI 加密，不能直接复制到另一个 Windows 账号解密。
- 本应用不会把账号凭据上传到开发者服务器；解析请求直接发往对应网盘服务。

## 已知边界

- 匿名能力取决于公开分享链接和服务方实时接口策略；“可浏览目录”不等于“可免登录下载”。
- 网盘接口可能随服务方更新而变化；真实账号和真实链接仍需在使用环境中验证。
- 本工具不绕过付费、权限或加密保护，只处理账号本身有权访问的内容。
