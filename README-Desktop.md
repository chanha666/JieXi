# 解析 Windows 版 4.1.2

## 安装版

1. 下载 `JieXi-4.1.2-Windows-Setup.exe`。
2. 双击安装，按提示选择位置。
3. 从桌面或开始菜单打开“解析”。
4. 卸载时进入 Windows“设置 → 应用 → 已安装的应用”。

安装包目前没有商业 Authenticode 证书，Windows 可能显示 SmartScreen 提示；请只从 `chanha666/JieXi` 的 Release 下载，并与 `SHA256SUMS.txt` 核对。

### 从旧版升级

- **3.1.0 及以上版本**：可以直接运行 4.1.2 安装包升级。安装器会在移除旧版之前，只把 `%LOCALAPPDATA%\解析` 中的 `state-v3.bin`、`state-v3.bin.bak`、`media-tasks-v1.json` 迁移到 `%LOCALAPPDATA%\JieXi\Data`；不会复制其他文件，也不会覆盖已经存在的新数据。遇到占用、冲突、校验失败或异常路径时，升级会停止并保留旧版与旧数据。
- **3.0.x 及更早版本**：安装器会安全阻止直接升级。请先备份 `%LOCALAPPDATA%\解析` 和重要下载记录，在 Windows“设置 → 应用 → 已安装的应用”中卸载旧版，再安装 4.1.2。不要删除备份，确认新版任务与下载文件正常后再自行整理。

4.1.2 延续数据分离设计，运行数据与程序安装目录分离，默认保存在 `%LOCALAPPDATA%\JieXi\Data`；正常卸载程序不会把这份用户数据当作程序文件删除。

## 绿色版

1. 下载并完整解压 `JieXi-4.1.2-Windows-Portable.zip`。
2. 双击文件夹内的“解析.exe”。
3. 不要只复制 EXE；`app`、`runtime`、媒体核心和许可证目录都必须保留。

绿色版和安装版功能相同。安装版会创建快捷方式并支持正常卸载；绿色版适合放在 U 盘或任意文件夹中直接运行。

## 使用

- 切换语言：我的 → 外观 → 语言 / Language，支持简体中文、繁體中文、English 与跟随系统；即时生效，不重启下载任务。
- 网盘分享：在“解析”粘贴链接和提取码，登录对应网盘后选择文件下载。
- 公开视频：在“解析”粘贴一个或多个视频链接，选择画质、格式和字幕后加入队列。
- 下载任务：在“下载”页查看网盘和媒体任务，执行暂停、继续、取消、重试、删除或打开目录。
- 本地处理：在“我的 → 媒体工具”使用图片局部修复、音频提取、视频截图和媒体信息导出。
- 故障反馈：在“我的 → 设置与更新”导出脱敏诊断包，再打开 GitHub 反馈页面。

默认保存目录为 `D:\解析下载`；D 盘不可写时使用当前 Windows 用户的下载目录。设置中可以改为其他文件夹。单任务默认不设速度上限，并发数并非越高越快；应用会在稳定范围内使用分片连接。

主导航与 Android 一致为「解析 / 下载 / 我的」。媒体工具、外观、认证备份、历史收藏、平台诊断、更新和赞赏都在「我的」；减少入口不等于删除功能。

## 登录与隐私

登录入口：**我的 → 网盘与账号**。夸克、UC、百度和 139 使用内置官方网页；123 支持账号密码登录，迅雷支持密码/短信登录；手动 Token、浏览器导入和加密备份保留为备用方式。个人文件浏览及管理入口是「我的 → 我的网盘文件」。凭据保存在“解析”的本机配置中，并由当前 Windows 用户的 DPAPI 加密。诊断日志会移除 Cookie、Token 和链接查询参数。

公开视频页没有强制登录按钮，但 YouTube 等网站可能因风控要求 Cookie 或验证码。遇到这种情况只能按原站要求授权，不能靠提高线程数或更换解析器绕过。

## 内置组件

发布包自带 Java 运行环境、yt-dlp、FFmpeg、ffprobe、Deno 和视频号提取插件，目标电脑不需要另装开发工具。程序启动时会检查组件是否齐全，打包流程会复核 `MANIFEST.sha256`。

正式 Release 固定提供五个附件：Windows 安装版、Windows 绿色版、Android APK、`SHA256SUMS.txt` 和 `BUILD-INFO.txt`。Windows 安装版当前未做 Authenticode 签名；Android APK 使用作者固定的 RSA 4096 位发行证书签名，两者不能混为一谈。
